# BigBasket Sales Dashboard

## Project Overview
This project analyzes BigBasket sales data to understand monthly revenue and category-wise performance.

## Analysis
The analysis includes:
- Monthly revenue trend
- Category-wise revenue
- Target performance by category
- Total revenue
- Total delivered orders
- Average order value
- Interactive category filter

## Key Insights
- Total Revenue: ₹88,282
- Total Delivered Orders: 434
- Average Order Value: ₹203.4
- 3 out of 6 categories met the revenue target.
